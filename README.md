# 민상파파 컴퍼니 · 원형 회의실

성남분당뷰티 AI 팀장 7명(블로그·유튜브·인스타·쿠팡 파트너스·체험단 정리·눈썹 시술 팀장 + 성남 청약·혜택 공지)이
원형 회의 테이블에 둘러앉아 지금 돌리고 있는 일을 한눈에 보는 대시보드입니다.
GitHub Pages에서 정적 페이지로 돌아갑니다: <https://woojinki74-oss.github.io/>

## 화면 구성

- 상단: 시계(KST), 마지막 업데이트 시각, 상태별 집계(운영 중·대기·확인 필요·일시정지), 오늘의 한 줄 요약
- 탭 칩: 팀장·공지 7개를 바로 고르는 목록 (모바일에서도 7개 모두 보입니다)
- 원형 회의실: 가운데 지니(총괄)가 대표님 지시를 받아 회의실로 내려보내고, 원형 테이블 위 차트·노트북·커피잔·화분 소품과
  그 둘레에 팀장 캐릭터가 앉아 있습니다. 캐릭터를 누르면 오른쪽(모바일에서는 아래) 패널에 담당 업무가 열립니다.
- 캐릭터 머리 아래 이름표에 상태(운영 중·대기·일시정지·확인 필요)가 색 점과 함께 붙고, 마우스를 올리면 오늘 할 일 말풍선이 뜹니다.

## 상태 바꾸는 방법

`status.json` 하나만 고치면 화면이 그대로 따라옵니다(열어 둔 탭은 5분마다 다시 불러옵니다).

```json
{
  "updated": "2026-11-22T09:20:00+09:00",
  "headline": "자동화 7개 중 3개 가동 · 다음 09:30 성남 청약 공지",
  "employees": [
    {
      "id": "blog",
      "name": "블로그 팀장",
      "emoji": "📝",
      "sprite": "sprites/blog.svg",
      "seat": 3,
      "state": "waiting",
      "stateLabel": "11:00 대기",
      "bubble": "오늘 11:00 초안 + 이웃 5명",
      "schedule": [{ "time": "매일 11:00", "text": "초안 + 이웃 5명" }],
      "details": ["..."],
      "last": { "at": "11-21 13:54", "text": "..." },
      "links": [{ "label": "블로그 열기", "url": "https://blog.naver.com/woojinki" }]
    }
  ]
}
```

- `state`: `running`(운영 중) · `waiting`(대기) · `paused`(일시정지) · `check`(확인 필요)
- `stateLabel`: 이름표에 보이는 짧은 상태 문구
- `bubble`: 캐릭터에 마우스를 올리면 뜨는 말풍선
- `seat`: 회의실 자리 번호 1~7 — 1·2 뒷줄, 3·4 좌우, 5·6·7 앞줄(가운데가 6번). 자리 위치는 `template.html`의 `.char.seat-*`에서 화면 폭별로 잡습니다.
- `index.html`에는 같은 내용이 내장되어 있어 `status.json`을 못 불러와도 화면이 비지 않습니다.

## 구성 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 대시보드 한 장 (스타일·스크립트 내장) |
| `status.json` | 화면에 보이는 모든 상태 데이터 |
| `sprites/*.svg` | 팀장 캐릭터 7명과 지니(총괄) 일러스트 |
| `template.html`, `build.py` | `status.json`을 `index.html`에 넣어 다시 빌드할 때 (`python3 build.py`) |
| `make_chars.py` | 캐릭터 SVG를 다시 만들 때 |

브랜드는 `성남분당뷰티` 기준으로 씁니다.
개인정보(전화번호, 주소, 생년월일, 계좌·포인트 잔액, 카톡 ID 등)는 이 페이지에 넣지 않습니다.
